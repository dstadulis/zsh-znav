1. Src/utils.c UTF-8 Byte Slicing in zsh_directory_name

In Zsh 5.9's C finddir(), dynamic directory contraction (mode d) advances past $reply[2] bytes, whereas Zsh's default MULTIBYTE ${#dir} counts characters. Returning character count 17 instead of byte count 18 on /private/tmp/café slices mid-codepoint into ~[cafe]$'\xa9'/sub! 

integer blen
{ setopt localoptions no_multibyte; blen=${#matched_dir}; }
typeset -ga reply=("$code" $blen)

2. macOS OpenDirectory Empty $userdirs Trap

On Linux (/etc/passwd), ${(k)userdirs} enumerates local users. On macOS Darwin (OpenDirectory), ${#userdirs} == 0 and ${+userdirs[root]} == 0—yet hash -d root=/repo clobbers ~root! zsh-znav detects every OS user in 0 forks via pre-projection tilde probing: 

(( $+userdirs[$cand] )) && return 0
(( $+nameddirs[$cand] )) && return 1
local tilde="~$cand"; [[ ${~tilde} != $tilde ]]

3. Bare float 10-Digit Truncation (~110 ms Precision Loss)

In Zsh, declaring bare float x formats $EPOCHREALTIME to 10 significant digits (1.795126494e+09) whenever stored into associative arrays or WAL files, losing ~0.11 s (500,000x worse than IEEE-754 roundoff). float -E 17 preserves lossless 53-bit round-trips (max |dLambda| == 0.000e+00). 

float -E 17 _cur _hl=$ZNAV_HALF_LIFE _tau _mx _diff _next
(( _tau = _hl / log(2.0) ))
(( _next = _mx + _tau * log(1.0 + exp(-_diff / _tau)) ))

4. Selective zsh/files & always-Block P10k Wrapping

Unfiltered zmodload zsh/files shadows /bin/mv and /bin/mkdir globally; zsh-znav loads only -F zsh/files b:zf_mv b:zf_mkdir for atomic POSIX rename(2) WAL compaction, and wraps Powerlevel10k prompt_dir in an exception-safe { ... } always { ... } block.
